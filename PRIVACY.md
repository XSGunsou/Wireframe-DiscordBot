# Privacy Policy for Wireframe Bot

1. **Data Collection**: Wireframe Bot collects basic server data necessary for bot function (e.g., Guild IDs, Voice/Text Channel IDs configured for logging and dashboard setup).
2. **Data Usage**: Collected data is strictly used to process music queue commands, send voice logs, and deliver message logs.
3. **Data Sharing**: We do not sell, share, or transfer your data to third parties.
4. **Data Deletion**: Server configuration data can be removed upon removing the bot from your server or contacting the developer.
